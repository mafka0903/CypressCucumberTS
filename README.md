# CypressCucumberTS

### Summary

CypressCucumberTS is an automated testing project for https://telnyx.com, built using the Cypress framework with Cucumber and TypeScript.

Links to test cases
https://docs.google.com/spreadsheets/d/1tS3XCV9NTeMYT2Q8NqY41bPv8zkPwb-NELOdAPnF2SE/edit?usp=sharing

### Requirements

Node v20.10.0

### Steps to install

1.  Clone the repository:

        git clone https://github.com/mafka0903/CypressCucumberTS.git

2.  Navigate to the project folder:

        cd CypressCucumberTS

3.  Install dependencies:

        npm install

### Steps to launch

1.  Run all tests:

        npm test

2.  Run tests in headed mode:

        npm cy-run

3.  Open Cypress Launchpad:

        npm cy-open

### Generating Allure Report

        npm genReport

Open report in browser:

        npm openReport

Reports also avaliable on GitHub pages https://mafka0903.github.io/CypressCucumberTS/
